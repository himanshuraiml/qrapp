## 1. Project Overview

| Field | Value |
|---|---|
| **App Name** | QR Attendance |
| **Platform** | Flutter (iOS target) |
| **Institution** | SRMIST, Trichy |
| **Developer** | Dr. Himanshu Rai |
| **Version** | 1.0.0+1 |
| **Flutter SDK** | ^3.7.0 |
| **Backend** | Google Apps Script (Serverless, Google Sheets) |

### What it does
A role-based mobile application that allows:
- **Faculty** to scan student QR codes to mark attendance
- **Students** to display their unique QR code and view attendance history
- **Admins** to manage faculty, configure session timings, and view all records

## 2. Architecture

### Pattern: MVC + Provider

```
lib/
├── main.dart                        # App entry point, portrait lock, MultiProvider
├── config/
│   ├── api_config.dart              # Base URL and timeout constants
│   └── app_theme.dart               # Colors, typography, reusable styles
├── models/
│   ├── user_model.dart              # Admin/Faculty data + role helpers
│   ├── student_model.dart           # Student data + QR data
│   ├── attendance_model.dart        # Attendance record + session helpers
│   └── session_settings_model.dart  # Session time config + current session logic
├── providers/
│   └── auth_provider.dart           # ChangeNotifier: auth state + login/logout
├── services/
│   ├── api_service.dart             # All HTTP calls to backend
│   └── storage_service.dart         # SharedPreferences wrappers
└── screens/
    ├── splash_screen.dart
    ├── login_screen.dart
    ├── admin/
    │   ├── admin_dashboard.dart
    │   ├── manage_faculty_screen.dart
    │   ├── attendance_records_screen.dart
    │   └── session_settings_screen.dart
    ├── faculty/
    │   ├── faculty_dashboard.dart
    │   └── qr_scanner_screen.dart
    ├── student/
    │   └── student_dashboard.dart
    └── shared/
        ├── profile_settings_screen.dart
        └── change_password_screen.dart
```

### App Boot Flow

```
main.dart
  └─ WidgetsFlutterBinding (portrait only)
  └─ MultiProvider → AuthProvider
  └─ SplashScreen
       └─ AuthProvider.initialize() (loads stored session)
       └─ Route based on role:
            Admin    → AdminDashboard
            Faculty  → FacultyDashboard
            Student  → StudentDashboard
            None     → LoginScreen
```

## 3. User Roles & Features

### Admin
- Dashboard stats: total/active faculty, today's & total attendance
- Manage Faculty: add, activate/deactivate, delete
- View attendance records with date/session/department filters
- Configure session times (FN/AN start and end)

### Faculty
- View current session (FN/AN) determined by time
- Scan student QR codes with camera
- View today's attendance list (top 10)
- Duplicate scan prevention within same session

### Student
- Display personal QR code (generated by backend)
- See today's FN/AN attendance status
- View recent attendance history (last 10 records)

### All Users
- Login / Logout
- Change password
- Profile screen

## 6. API Reference

### Backend
- **Type:** Google Apps Script Web App
- **Data Store:** Google Sheets (serverless)
- **Base URL:** defined in `lib/config/api_config.dart`
- **Timeout:** 30 seconds

### Endpoints

#### Auth
| Method | Action | Params |
|---|---|---|
| GET | `/login` | `email`, `password` |
| GET | `/studentLogin` | `studentId`, `password` |
| POST | `/changePassword` | `userEmail`, `currentPassword`, `newPassword` |
| POST | `/changeStudentPassword` | `studentId`, `currentPassword`, `newPassword` |

#### Faculty Management
| Method | Action | Params |
|---|---|---|
| POST | `/addFaculty` | `adminEmail`, `facultyEmail`, `facultyName`, `facultyPassword` |
| GET | `/getFaculties` | `adminEmail` |
| POST | `/updateFacultyStatus` | `adminEmail`, `facultyEmail`, `status` |
| POST | `/deleteFaculty` | `adminEmail`, `facultyEmail` |

#### Attendance
| Method | Action | Params |
|---|---|---|
| POST | `/markAttendance` | `facultyEmail`, `studentId`, `studentName`, `department`, `section`, `year`, `session` |
| GET | `/getAttendance` | `date?`, `department?`, `section?`, `session?` |
| GET | `/getTodayAttendance` | — |

#### Student
| Method | Action | Params |
|---|---|---|
| GET | `/getStudentQR` | `studentId` |
| GET | `/getStudentAttendance` | `studentId`, `date?` |
| GET | `/getStudents` | — |
| POST | `/addStudent` | `adminEmail`, `studentId`, `studentName`, `department`, `year`, `section?` |

#### Dashboard
| Method | Action | Params |
|---|---|---|
| GET | `/getDashboardStats` | `adminEmail` |

### Response Format
All responses return JSON with at minimum:
```json
{ "success": true | false, "error": "message if failed" }
```

### QR Code Data Format
QR codes encode a JSON string:
```json
{
  "Student_ID": "REG123",
  "Name": "John Doe",
  "Department": "CSE",
  "Section": "A",
  "Year": "2"
}
```

## 7. State Management

### AuthProvider (`providers/auth_provider.dart`)
Uses Flutter `ChangeNotifier` via the `provider` package.

**State:**
```dart
UserModel? _user
String? _userType     // 'staff' | 'student'
bool _isLoading
String? _error
bool _isInitialized
```

**Key Methods:**
- `initialize()` — Restore session from SharedPreferences on boot
- `login(email, password)` — Staff/Admin login
- `studentLogin(studentId, password)` — Student login
- `logout()` — Clear all state and storage
- `changePassword(current, new)` — Update staff password
- `changeStudentPassword(current, new)` — Update student password
- `clearError()` — Reset error state

**Local Storage Keys (SharedPreferences):**
- `user` — JSON string of UserModel
- `user_type` — `'staff'` or `'student'`
- `is_logged_in` — boolean
- `student_data` — extra student metadata

## 8. Authentication Flow

```
Startup
 └─ Load session from SharedPreferences
 └─ If found → route to role dashboard
 └─ If not → LoginScreen

Staff Login
 └─ Email + Password → GET /login
 └─ Save UserModel + user_type='staff' to storage
 └─ Route: Admin → AdminDashboard | Faculty → FacultyDashboard

Student Login
 └─ RegNo + Password → GET /studentLogin
 └─ Save UserModel + user_type='student' + student_data to storage
 └─ Route → StudentDashboard

Logout
 └─ Confirmation dialog
 └─ Clear SharedPreferences
 └─ Route → LoginScreen (replacement)
```
